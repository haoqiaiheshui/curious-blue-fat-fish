# 好奇的蓝色大肥鱼（Curious Blue Fat Fish）

> 一套自托管的 QQ AI 伴侣工程：把一只 QQ 号养成住在群里的 AI 群友。

> 把一只 QQ 号养成「住在群里的 AI 群友」——能聊天、能看群文件、能发说说、能自己刷视频听歌，
> 掉线会自愈，花钱有额度，睡觉会断网省电。

一套围绕 **NapCat + DeepSeek Harness (DSH) + qq-bridge** 搭起来的自托管 QQ 机器人工程。
本文档描述整体架构、各模块职责、部署步骤与安全边界。

> ⚠️ **先读安全须知**：本项目使用第三方协议端登录 QQ，属于非官方客户端行为，
> 存在账号被风控/限制的风险。请只在自己的小号上使用，并阅读 [docs/SECURITY.md](docs/SECURITY.md)。

---

## 它能做什么

| 能力 | 说明 |
|---|---|
| 群聊 / 私聊 | 有记忆、有人设、会接梗、会主动开话题，也会选择性潜水 |
| 看群文件 | 群里发的 docx/xlsx/pptx/pdf/图片都能读进来理解 |
| QQ 空间 | 读说说、发说说（每天 1~2 条限额）、**手动**评论/点赞 |
| 空间巡游 | 每小时自动给好友动态点赞（可关） |
| 娱乐自动化 | 在安卓模拟器里刷 B 站、听网易云、看热搜（ADB 界面自动化）|
| 生活作息 | 00:25 说晚安、07:35 说早安；00:30-07:30 睡眠时段只留核心服务 |
| 掉线自愈 | 2 分钟探活，自动重登；需要扫码时把二维码推送到手机 |
| 额度控制 | 每天 ¥10 预算，70% 提醒、85% 自动停娱乐功能 |
| 远程运维 | 主人在 QQ 私聊用口令下发指令（重启/截图/跑命令），群友拿不到权限 |
| 桌面挂件 | 桌宠常驻显示今日已用/剩余额度 |

## 快速开始（摘要）

完整步骤见 [docs/SETUP.md](docs/SETUP.md)。

1. **准备**：Windows 10/11、Node.js ≥ 20、16GB 内存、一个 QQ 小号
2. **NapCat**：下载 OneBot 协议端，用小号扫码登录，开启 WS(3001)/HTTP(3000)
3. **DSH**：安装 DeepSeek Harness，配置模型 provider
4. **qq-bridge**：填 `config.json`（群白名单、私聊白名单、ownerQQ），`node src/bridge.js`
5. **可选模块**：按需启动守护脚本（掉线/额度/睡眠/娱乐）

## 设计原则

1. **双通道分权**：模型只有 QQ 工具；本地执行能力挂在桥接的指令层，只对主人开放。
2. **失败可恢复**：任何守护进程挂掉都能被重新拉起；掉线 2 分钟内自愈。
3. **花钱有上限**：所有 LLM 调用都经过额度守护，超阈值自动收缩功能。
4. **像人不像客服**：人格提示词刻意降低「有求必应」倾向，允许装傻、拒绝、潜水。
5. **风控优先**：登录频率退避、白名单准入、自动点赞低频、敏感话题过滤。
